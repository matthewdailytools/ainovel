# 凡人流原创写作

以人物处境、风险取舍、资源成长和行动因果组织原创仙侠，用具体的观察、对白、心理与动作形成正文。这里的规则是人工归纳的创作偏好，尚未经原著语料验证；不要声称已经蒸馏原著、能够精确复现作者或保证相似比例。

## 先对齐本次任务

- 根据用户请求区分构思、续写、改写、诊断，以及建议、半自动、全自动的创作分工。诊断请求给问题与依据，不擅自改稿。
- 保持用户锁定的情节、结果、人物命运、设定和可揭示信息；写法偏好服从这些安排。只在已授权范围内补充。
- 优先使用当前正文、已采用设定、人物所知、能力和资源状态。不把计划中的成长、传闻或模型记忆变成当前事实。
- 资料不足时可以从小范围继续。关键结果未定且不在本次决策权限内时，给少量选项或写到确定边界，不要求先建完整设定库。
- 延续用户给定的人称、视角、时间顺序和人物声音。新作未指定时，可暂以第三人称跟随当前焦点人物，后续可调整；这不是对原著全书视角的断言。

## 叙事与表达的工作准则

1. **处境推动选择。** 让读者理解人物当下想得到什么、受什么限制，以及为什么此时采取该行动。人物可以误判、动情或冒险；谨慎表现为具体取舍，不写成永远撤退或永远正确。
2. **成长有过程。** 获得材料、得到方法、学会运用、具备条件和完成突破分别处理。收益与代价会改变后续行动，但休整或关系场景也可以独立承担作用。
3. **信息影响行动。** 分清角色事实、角色猜测和读者所知。揭示信息后，让它有机会改变判断或选择；没有获知依据时，不用他人的内心替人物补齐答案。
4. **因果进入正文。** 将重要准备、手段限制和环境条件连接到结果。次要过程可以概述，决定成败的变化适当展开。
5. **语言清楚而有变化。** 以自然白话、具体动词和清晰指代为基调，随场景调整句长、停顿与叙述距离。修辞、感官和直接心理都可以使用，避免同一效果反复解释。
6. **说明服务当前理解。** 在读者需要理解选择、风险或结果时交代相关规则。保留必要说明与时间概述，不机械要求所有内容都通过动作展示。
7. **人物保持差异。** 用话题目的、措辞、行动方式和立场区分角色。性格和处事方式随经历、实力与关系变化，不把所有人写成同一种冷静算计。
8. **张弛符合场景。** 用未完成的目标、后果或新信息承接后文，也允许自然收束。不要把每章都写成固定的试探、反转、获宝和强行悬念。

这些准则用于实现用户选定的阅读目标；发现与本次表达意图不符时调整，不把它们宣称为所有仙侠或原著的唯一规律。

## 按场景补充指南

- 打斗、伏击、追逃、斗法、脱身：读取[打斗指南](references/combat.md)，重点处理攻防互动、空间、判断与消耗。
- 人物、环境、心理、对白、法术法宝和修炼描写：读取[描写指南](references/description.md)的相关部分。
- 混合场景同时使用必要部分；用户只改一段环境时，无需加载整套打斗指导。
- 若用户另给偏好或参考片段，用它校准表达选择；不要把示例中的专有设定和事件默认移入当前故事。

## 交付前核对

对当前生成或修改范围检查并修正：

- 固定情节与结果是否保持，新增内容是否超出本次分工。
- 人物行动是否符合当前所知、能力、位置、伤势与资源。
- 关键动作和指代是否清楚，结果是否有相关条件支撑。
- 描写是否有具体对象与作用；心理、解释和气氛是否反复表达同一意思。
- 场景是否出现用户选定的表达倾向，同时保留人物与场景差异。

默认交付用户请求的正文、候选或诊断。用户只要正文时不附流程表或规则清单；只有请求审查记录时，给简短问题、依据和修改说明。局部检查不声称已经核验全书连续性；无法兼顾的硬性条件需明确指出。

生成结果先作为候选，按当前创作流程采纳。使用本 Skill 不代表可以自动替换原稿、扩大运行范围、调用付费服务或启动全书蒸馏。
