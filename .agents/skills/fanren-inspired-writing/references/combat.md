# 打斗与行动指南

按当前场景选用。以下是人工整理的创作准则，具体胜负由用户情节和作品规则决定，不构成对《凡人修仙传》原文的分析结论。

## 战斗的决策条件

写清会影响这场行动的少量条件：双方想达成什么、彼此知道多少、距离与遮蔽物、当前能力限制，以及可用的武器、法术、物品和退路。只有与选择相关的条件才需要展开，不在正文列战力面板。

人物的目标可以是取胜、拖延、护住东西、探明手段、遮掩身份或脱身。按目标判断行动价值；逃出追击也可以是有效结果。若用户锁定“不战斗”，不能因为此指南鼓励冲突而主动开战。

## 攻防怎样写进正文

- 将关键交换写成可理解的“行动—应对—变化”。对手会行动和应变，不是依次承受展示招式。
- 当判断决定动作时，交代人物感知到的线索与必要判断；立即反应可以先写动作，随后补充读者需要的原因。
- 用相对位置、移动方向、障碍和时间差说明为什么能躲开、拦住、逼近或失手。不要求每次移动都精确报数。
- 手段的效果来自已有规则或本次明确建立的条件。关键时刻出现新能力时要有依据；不能用临时新增的万能底牌抹平困境。
- 写出攻击与防御的接触结果，如受力、偏转、损伤、失衡、范围变化；感官效果应帮助读者理解交互。
- 强弱差可以影响选择，但胜负不只由等级宣布；克制、准备和环境优势同样需要正文依据。

## 不同场景的笔墨

| 场景 | 值得展开的内容 | 可以概述的内容 |
|---|---|---|
| 突然遇袭 | 察觉危险的线索、第一反应、局面如何改变 | 与当前反应无关的长篇背景 |
| 追逃 | 路线、阻碍、诱导、追踪依据、速度与耐力限制 | 没有新变化的重复奔跑 |
| 准备后交手 | 准备在哪里奏效，对手如何识破或改变条件 | 所有准备都重新逐项复述 |
| 势均力敌 | 试探得到的信息、攻防调整、胜负条件的变化 | 没有作用的连续招式名称 |
| 明显压制 | 压制怎样体现、弱方还剩哪些选择 | 注定不影响局势的每次碰撞 |
| 多人混战 | 当前焦点、关键位置、联盟与目标变化 | 逐人轮流报完全部动作 |

不要把表中的每一项都塞进一场戏。读者需要的是可跟随的局势变化。

## 详略、心理和后果

决定成败的交换展开，重复过程压缩。让紧张来自时间、选择和后果，也允许短暂停顿观察；避免每一击后都插入一段完整推演。

人物不必总能看穿手段。根据其经历和当下信息，保留猜测、误判和被迫反应；后续揭示应与此前可观察的现象相容。

结束后延续相关伤势、法力、物品损耗、位置、暴露和敌我认知。是否需要处理痕迹、检查收获或撤离，由本次情节决定，不能套用固定收尾。

## 自拟的表达示意

以下例句仅说明空间与动作因果，不是原著引文，也不要求模仿其句式：

> 车辕挡住了来人的半边身子。他没有追着刀光后退，反而侧身贴近车轮，让那柄长刀先撞上木架。木屑溅起时，他才看清对方空着的左手。

这个片段建立了遮挡、接近、碰撞与新观察。若当前人物不具备完成该动作的条件，或后续锁定情节不允许这样发展，就应换写。
