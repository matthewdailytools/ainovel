# 人物、环境与过程描写指南

以下是本 Skill 选定的表达偏好。根据当前人物、场景用途和用户要求调整，不将其当作已验证的原著文风统计。

## 环境：建立可感知的处境

选择当前焦点人物会注意到的细节。人物正在辨认追踪者时，脚步、尘土和遮挡更相关；休整、初见或情绪场景可以留出纯粹感受环境的笔墨。

让空间、光线、声响、温度、气味或材质构成有主次的感受，不要求五感齐全。与行动有关的细节可以参与后续因果；也允许细节只承担气氛、节奏或情感作用。

## 人物：细节和行为相互支撑

按叙述距离选取外貌、穿戴、姿态、声音或习惯。身份与性格可以通过具体表现逐渐显出，不一次堆完整人物卡。

神态和动作应与人物当前意图、状态相容。单次皱眉或沉默不能直接证明对方在撒谎；焦点人物可以因此怀疑，但叙述要保留判断的性质。

## 心理：判断有对象，情绪有变化

心理可以直接叙述，也可以借感知、联想、语言与行动呈现。写出当前真正影响选择的内容，保留人物可能不理性、矛盾或迟疑的空间。

观察、解释、权衡和决定可按需要组合，不要求每次齐全。情绪已经被具体表现之后，只有新判断或新变化才值得再次展开，避免连续重复“担心、警惕、不安”。

## 对白：人物各有目的和声音

根据关系与处境决定称呼、语气、长短、信息量和言外之意。交涉可以试探，亲近人物也可以坦率、闲谈、争执或沉默；不要让所有对白都变成相同的机锋。

重要交谈中，区分说出口的内容、人物真实意图和对方的理解。依照当前视角呈现可知部分。必要时插入动作、停顿或环境反应，让对白与场景连在一起。

## 法术与法宝：让读者理解作用

从本次需要中选取外形、材质、发动方式、感官效果、作用对象、范围或限制。登场时不要求写完百科；关键功能影响结果时，要给足理解依据。

变化可以通过接触、形变、声音、轨迹、遮蔽或人物反应呈现。强烈光色只是手段之一，避免用连续的“威压惊人、天地变色”替代具体作用。

名称不自动说明能力。新物件的功能只能在本次允许补充的范围内确定；用户已设定的限制持续生效。

## 修炼与成长：过程有差异

区分想达到的阶段、已有方法、本次尝试、可观察反应和实际结果。材料、时间、领悟或身体状态的限制以作品资料为准，不编造精确成功率与消耗。

第一次出现、遇到新困难或导致重大变化时可以细写；重复而稳定的练习适当概述。修炼也可以承载期待、挫败、孤独或关系变化，不必每段都产生突破。

## 句式与节奏

- 以具体对象和清楚指代连接句子，重要动作避免主语不明。
- 根据观察、判断、动作和概述改变句子长度，保留自然转折与承接。
- 比喻和形容用于增强当前感受，不连续更换不同意象描述同一效果。
- 段落围绕当前观察、交流或局势变化组织，按阅读需要换段，不机械一句一段。
- 允许适量说明与留白；用户偏好更抒情、更密集或更简洁时，调整本节倾向。

## 自拟的表达示意

以下是为说明描写作用而写的例句，与原著没有引文关系：

> 庙门只开着一道窄缝，门槛内侧却没有积灰。他停在檐下，先把湿透的袖口拧了一遍，目光仍留在那条干净的木棱上。

这里用环境差异引出人物注意，再通过动作保留停顿。它可以表达怀疑，不能仅凭这几句就断言屋里一定有人；后续结论由当前故事决定。
