# 小说违规内容与发布风险审核

判断具体表达或发布行为可能触及什么规则、证据是否足够、可能影响哪个对象。文学效果、平台收录、涉嫌违法和账号封禁分别判断，不用“敏感词命中”替代语义审核。

## 先确定适用范围

沿用作者已给的平台、发布渠道、受众、正文版本、检查范围和处罚通知。未指定时，先按中国大陆公开发布做通用风险筛查，标明目标平台未确定；可并列参考番茄、起点、晋江，不把任一平台细则当作全行业标准。

只有缺口会影响具体结论时才补充询问，例如角色是否未成年、是否影射可识别真人、是否已获授权。缺少这些资料时仍可检查其他部分，将相关结论留为待核实，不要求先交完整设定。

## 核心判断

- **规则优先核实。** 索引核验基线为 2026-11-14，属于可更新的研究快照。实际发布审核或“最新风向”请求应重新查阅目标官方规则与近期公告；无法联网时明确按旧快照评估，不能称现行规则已验证。征求意见稿不能当生效规定。
- **分开结论。** 使用“公开规则与证据匹配／存在风险、需复核／本范围未发现”，并分别注明法规风险、平台限制、权益争议或发布行为问题。司法违法认定、平台实际处罚和模型建议不同。
- **描写要看语境。** 反派行为、受害叙述、反诈说明、历史研究不自动等于宣扬；批判立场也不能豁免露骨色情、伤害性细节或平台明确限制。题材、取向和身份标签不单独构成违规判据。
- **词表只作线索。** 没有官方公开词表就不编造“平台黑名单”。字词规避不会消除实质风险，不建议谐音替换、拆字、转图片或外链传递违规内容。
- **分清处罚对象。** 章节退回、作品下架、停止推荐、收益或签约限制、账号禁言与永久封禁不能互换。根据规则和通知列可能措施，不捏造封禁概率、必封阈值或固定处罚阶梯。
- **证据与覆盖真实。** 引用能定位的最少原文，重复引文消歧；涉及未成年人色情、真实隐私等仅保留识别问题必要的信息，报告可摘要或遮盖敏感值。不得补造露骨细节、侵权对照、账号历史或平台回执。

## 交付

先给平台与规则日期、实际检查范围、总体风险及限制，再逐项说明：

`位置及必要证据 → C 类别 → 具体规则与链接 → 风险判断及不确定性 → 可能处置对象 → 最小处理建议`

高风险优先处理，但不把待核实项说成已违法。无发现只适用于已读范围和已核实规则，不承诺可过审、不会被封或收益正常。

作者只请求审核时不改稿。明确授权修订后交付候选，复检原问题和相关平台限制；作者偏好不会使违规风险自动消失。实际发布、申诉提交、删除作品、改账号及应用采纳仍需相应授权，本 Skill 不自动执行这些动作，也未接入工作台审核链路。
