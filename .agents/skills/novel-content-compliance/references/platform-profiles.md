# 平台差异、处置对象与近期风险

核验基线：2026-11-14。以下为公开规则快照；来源编号见[证据索引](sources.md)。处罚条款允许的措施不等于每次都会执行，公告案例也不是所有作者的封禁概率。

## 1. 先说明“被封”指什么

| 对象 | 可能表现 | 不能直接推断 |
| --- | --- | --- |
| 章节／素材 | 驳回、锁章、屏蔽、要求修改 | 不等于整部作品或账号永久封禁 |
| 作品 | 停止推荐、限制分发、下架或不予收录 | 无流量本身不能证明受罚；下架原因应看通知 |
| 签约／收益权益 | 拒绝签约、取消奖励或限制结算等 | 不是所有平台都有相同措施；按具体规则、合同与通知核对 |
| 账号／合作资格 | 禁言、限制功能、封禁、永久关闭或不合作 | 不存在通用“先警告几次才封”的顺序 |
| 法律责任 | 权利投诉、民事争议或行政刑事处理 | 平台封禁不等于法院已认定违法，平台不处理也不等于合法 |

平台事实分别在下文来源支持；上表只是解释术语，不增设应用处罚机制。

需要结构化敏感内容警告、被举报或官方点名清单时，读取[警告与案例清单](warning-cases.md)：C01—C26表示原因，B01—B08表示处置对象与措施；来源标签及事件状态另记。举报、受理、点名不直接等于已封禁，未注明期限的封禁不能写成永久。清单包含历史事件，不替代本页当前规则快照。

## 2. 番茄：覆盖正文、作品资料及账号行为

P01 细化色情低俗、未成年人、暴力、标题封面及其他驳回原因，严重情形可涉及下架和账号合作；P02 将正文、社区、主页等纳入范围，并分别规定内容与账号措施。以目标页面及具体通知核对，不能只检查正文章节。[内容安全须知](https://fanqienovel.com/writer/zone/article/7231069121566212151/)、[平台发布规范](https://fanqienovel.com/writer/zone/article/7237084151751376957)

2026年公开处置中，以下风险有明确实例或专项依据：

- **大规模量产低质及提醒后不整改。** 2月4日公告针对批量粗制滥造、AI拼凑与恶意占流，明确措施可到永久封禁；不能扩展成禁止全部AI辅助。[P03公告](https://fanqienovel.com/writer/zone/article/7602950185735438398)
- **极端短故事与恶意群体对立。** 7月14日公告针对恶意失实丑化公务人员、极端家庭伦理叙事和性别污名对抗，列有下架、限流及账号措施；其范围和表现条件要保留。[P04公告](https://fanqienovel.com/writer/zone/article/7662315418110918718)
- **版权违规有实际账号处置。** 11月11日发布的10月公告分别列出版权违规网文下架3852篇、账号封禁331个；版权违规短故事下架5354篇、账号封禁86个。类别可能存在交叉，不能相加推算独立作者数，也不能据此计算被封率。[P05公告](https://fanqienovel.com/writer/zone/article/7706792381944709182)
- **审核后恶意改成色情低俗内容。** 3月6日发布的2月公告列出相关永久封禁案例。审核过的旧版本不保证后来修改稿合规。[P06公告](https://fanqienovel.com/writer/zone/article/7614109879669637144)

以上是可验证的治理重点，不能推测隐藏算法、统一词表、全行业门槛或未来处罚强度。

## 3. 起点：通用协议与社区规则分开使用

本次核实的《用户服务协议》版本为2024-04-28，第13、15条支持对内容、合法来源、AI非真实信息标识及账号措施的检查。第13.2条列有拒绝发布、删除、限制功能和永久关闭等不同措施；完整作家正文内部尺度未取得，不能据此编造亲密场景字数、锁章次数或签约阈值。[Q01协议](https://acts.qidian.com/pact/user_pact.html)

《社区公约》可用于评论、互动、标题、图片等社区场景。不要把社区禁言期限、评论尺度或配图协议未经核对套成小说正文的专门处罚标准。[Q02公约](https://acts.qidian.com/pact/community_pact.html)

若平台通知只说作品待修改，报告也只说明该对象；缺少账号通知时不宣布作者已被封号。

## 4. 晋江：章节亲热尺度与站外内容引导需单独核对

公开《简易审核标准》对章节中的亲热、性相关过程、隐晦长段、血腥暴力及站外违规内容引导有明确限制；以含蓄手法叙述过程也不自动符合标准。文案和作者专栏对外站信息另有规则与有限例外，应按发布位置核对。[J01标准](https://www.jjwxc.net/backend/examineStandard.php)

该页说明锁章相关问题需全面清理，但不是完整账号处罚手册。本轮未取得完整封号阶梯，因此只能说明相关内容可能不通过或锁章，账号处罚需要另核通知或其他有效规则，不能借用番茄的永久封禁条件。

## 5. 哪些情形值得优先人工复核

以下是本项目根据规则与案例作的审核优先级归纳，不是平台官方打分：

1. 未成年人色情、明显色情传播、现实伤害教唆、严重隐私侵害等有清楚规则指向的内容。
2. 大量具体表达搬用、未授权素材或版权投诉已有实质证据。
3. 目标平台明确治理的猎奇详写、恶意群体对立、违规站外引流。
4. 有记录的反复违规、恶意重传、审核后换成违规稿，或量产低质且不整改。
5. 标题封面、作者说、评论或外链与正文检查结果不一致，造成未被检查的传播入口。

一般创作瑕疵、一次驳回、用了AI、包含某个词或受到读者批评，都不足以单独证明将被封禁。没有规则分母和个案记录，不给“风险百分比”；规则允许的最严重措施要标为可能，不写成必然。
