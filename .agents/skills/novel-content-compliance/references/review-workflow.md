# 内容审核与合规修订流程

## 1. 选规则与范围

记录平台、公开／私用场景、受众、媒介、稿件基线、已读范围、作者提供的授权或通知，以及实际核实的规则版本。只审核一段时不默认封面、全书和账号历史也已核实。

当前平台规则优先查其官方页面和正式通知，法律风险再按适用法域及规范核对。法规、平台规则、个人合同各有适用范围，不能以一方的宽松规则免除另一项义务；规则冲突或解释不清时保留待核实。

未指定平台时完成通用筛查，并可列目标平台差异；没有作品内容时只做规则解释，不生成“该作品已违规”的结论。索引过期、页面不可读或仅有摘要时，说明实际证据层次。

## 2. 分三遍检查

- **第一遍：内容及权益。** 在已读正文、标题、简介、可读取图片中按目录选相关类别，优先核对年龄、可识别真实对象、性化与伤害细节、犯罪可操作性及权利来源。
- **第二遍：上下文及例外。** 对信号回读必要前后文，区分虚构／现实、叙述／宣扬、求助／诱导、正常交流／违规引流。标签、词表命中或反派台词都不能单独决定结论；批判结尾不自动抵消过程违规。
- **第三遍：传播与账号。** 只依据现有发布记录、通知和授权核对C21—C26。缺少合同、历史、原图或对照来源时记录覆盖限制，不把缺资料算成新的正文违规。

整体任务可巡视目录，但不为每类制造一个问题。一个根因关联多个类别时合并记录，保留影响位置；只查某项的请求不擅自扩为完整法律审计。

## 3. 问题的三个维度

| 维度 | 表达方式 | 判断依据 |
| --- | --- | --- |
| 证据状态 | 与公开规则匹配／存在风险需复核／本范围未发现 | 实际原文、有效来源及规则适用条件；定位不唯一不等于问题不存在 |
| 优先级 | 优先处理／需核实后处理／一般提醒 | 潜在伤害、规则明确程度、传播范围；这是审核建议，不是平台官方等级 |
| 可能影响 | 章节、作品、签约收益、账号、权益争议 | 具体规则列出的对象和措施；账号处置需额外事实，不由词频推断 |

逐项至少包含必要原文或位置、C编号、规则与链接、为什么适用、尚缺什么、可能处置对象和最小修订方向。若仅有作者描述而无原文，标明“按描述作初步风险提示”，不编造逐字证据。

报告中只保留定位所需的最少敏感片段；未成年人色情使用非露骨摘要，真实个人信息遮盖。没有侵权对照时不能声称完成查重；没有图像时不能宣布封面合格；不能通过去识别化报告推断原稿已经去识别。

## 4. 修订与复检

只审核时给问题及建议，不自动改稿。明确授权后针对原问题给候选：删减不必要的刺激或可操作细节，改为与情节有关的非露骨叙述，移除真实隐私、违规引流，补合法授权或调整未获许可的表达。改变关键情节、年龄、身份或作品方向时明示影响，不偷偷改事实。

合规修订处理实质风险，不靠谐音、拼音、拆字、转图、密码、外站链接等保留原内容来绕审。补一句“纯属虚构”“禁止模仿”“仅供成人”不能自动让正文通过；仍按实际内容和平台规则复核。

复检同一问题、关联人物年龄、描写目的、过程细节、资料版权与传播入口，分别记录已缓解／未解决／无法确认。“删掉被圈词”“换个词”“平台以前通过”均不等于问题消失。普通定向改稿按本项目最多两轮约定保留记录，到限不无限循环。

保留原稿、候选和报告的独立身份。Skill 输出尚不是工作台可应用的有效独立审稿报告；不自动进入 `revision.targeted`，不新增应用阻断或处罚状态。

## 5. 处理驳回或处罚通知

先读取作者提供的实际通知，核对平台、作品／章节／账号、稿件版本、原因、期限和是否存在可用申诉入口。不同对象分别处理，不能因作品搜不到、流量低、审核久就认定账号封禁。

能核实时列出对应原文、已做的实质修改、授权或原创证据及仍需解释的事项；只形成可审阅材料。没有明确授权不代作者提交申诉、联系平台、举报别人、删作品或注册新账号。没有处罚理由时不编造，也不建议规避封禁。
