# 违规内容与发布风险目录

26 类是便于审核的工作分类，不是26种独立违法行为。一个片段可涉及多类，按根因合并；证据不足时标风险或待核实。来源编号统一在[证据索引](sources.md)中查阅。

## 一、公共内容与未成年人风险（C01—C15）

出版禁止内容与未成年人限制分别见[网络出版规定](https://www.nppa.gov.cn/xxgk/fdzdgknr/zcfg_210/bmgz_213/202112/t20211209_442163.html)及[未成年人条例](https://www.cac.gov.cn/2023-10/24/c_1699806932316206.htm)；违法信息与不良信息的区分见[生态治理规定](https://www.cac.gov.cn/2019-12/20/c_1578375159509309.htm)。下列边界是审核方法，不是对具体稿件的豁免。

| 编号 | 风险类别 | 重点核对的表达 | 边界与依据 |
| --- | --- | --- | --- |
| C01 | 宪法原则、国家统一及安全 | 触及相关法定禁止事项的煽动、宣扬或内容 | 不按“涉及政治”四字一概判定；核实具体陈述与适用条款。L01、L02 |
| C02 | 国家秘密与保密属性待核实的信息 | 疑似涉密非公开资料，或作者明确来自受保密约束的材料 | 不能因写到真实地点设施就认定涉密；虚构设定与真实资料分开，保密属性需核实。L01、L02 |
| C03 | 恐怖主义、极端主义 | 宣传招募、合理化恐袭或提供现实实施支持 | 侦查、反恐情节仍核对细节与立场，不因反派出现即命中。L02、L03 |
| C04 | 民族仇恨、民族歧视 | 针对真实民族群体的煽动、污名和去人性化 | 普通人物矛盾与对真实群体的号召区分。L01、L02 |
| C05 | 宗教政策、邪教与迷信宣扬 | 现实招募、鼓吹邪教或以迷信实施诱骗 | 仙侠、神话、虚构宗门不按题材名自动判违规；目标平台另核。L01、L02、P01 |
| C06 | 英烈与重大历史、人物失实 | 侮辱英烈，恶意歪曲特定史实人物等 | 重大选题由出版服务方核实适用与备案，不把其义务全转给作者；不等于一切历史改编被禁。L01、L02、P01 |
| C07 | 谣言、虚假现实信息及灾难炒作 | 将编造的现实事件当事实传播，恶意炒作灾难 | 小说架空事件与现实爆料分开；“纯属虚构”不能掩盖可识别现实造谣。L02、Q01 |
| C08 | 淫秽色情与性化挑逗 | 以色情刺激为目的的露骨过程、身体聚焦或长篇性化内容 | 成年、自愿、付费或18+提示均不能保证合规；正常情感也不能仅凭词命中。L01、L02、P01、J01 |
| C09 | 未成年人色情或性剥削 | 未成年身份与色情化表达、交易或剥削相结合 | 优先核实年龄和上下文；无原文不虚构引文，不能仅改年龄数字就宣布解决。L03、P01 |
| C10 | 性犯罪与性暴力猎奇 | 对侵害过程、手段进行刺激性详写、赞美或招徕 | 受害者求助和非露骨追责叙述不自动等同于宣扬；平台过程尺度另核。P01、Q02、J01 |
| C11 | 血腥、残虐与暴力渲染 | 酷刑肢解的感官详写、鼓吹残虐或恐怖刺激 | 战斗结果、伤情概述与猎奇过程分开；不以打斗字数设通用阈值。L02、P01、J01 |
| C12 | 教唆犯罪或现实可执行方法 | 可直接用于现实作案的步骤、组织协助或规避追查方法 | 罪案题材不自动违规；核对细节的可操作性，不在报告中复述危险教程。L01、P02 |
| C13 | 赌博、毒品及非法交易推广 | 鼓励参与、交易联系方式、招募或促成交易 | 反诈反毒、调查与后果叙述分开；不能因出现名称直接判推广。L01、L03、P02 |
| C14 | 自残自杀诱导及危险模仿 | 鼓励、浪漫化伤害，提供可模仿方法或挑战 | 非操作性的痛苦、求助与恢复叙述分开；不得为审核补写方法。L03 |
| C15 | 未成年人负面诱导与欺凌 | 面向未成年人的危险诱导、欺凌宣传或有害接触 | 青春成长与学校冲突不自动禁止；适用受众和发布场景要明确。L03、P01 |

## 二、真实权益与平台价值限制（C16—C20）

真人名誉及隐私见[民法典人格权编](https://www.cac.gov.cn/2020-06/01/c_15925617772683193.htm)，版权见[著作权法](https://fjca.miit.gov.cn/zwgk/zcwj/wjfb/art/2020/art_3fd5e3c5e6624d95af229036f95e20d3.html)，现实网暴见[网暴治理规定](https://www.cac.gov.cn/2024-06/14/c_1720043894161555.htm)。平台附加限制按其原文核对，不直接升级为法律定性。

| 编号 | 风险类别 | 重点核对的表达 | 边界与依据 |
| --- | --- | --- | --- |
| C16 | 特定真人或组织的名誉侵害 | 可识别原型、捏造负面事实、侮辱或冒名 | 需核实识别性、事实与语境；不能因情节偶合或人物负面就断言侵权。L04、Q01 |
| C17 | 隐私、个人信息及肖像 | 真实住址、联系方式、病历、私密影像，尤其未成年人信息 | 授权和合法使用范围须有依据；报告遮盖敏感值，不补查真实身份。L03、L04 |
| C18 | 网暴、群体攻击与引战 | 对现实个人的组织围攻、人肉及煽动性别或地域敌意 | 具体人物争执、合理批评与针对群体的污名号召分开。L07、P02、P04 |
| C19 | 抄袭、洗稿及素材权利 | 搬用具体表达、未授权改编、图片封面及资料使用越权 | 必须有对照与权利信息；相同题材、套路或模型印象不能单独定侵权。L05、Q01 |
| C20 | 极端猎奇与公序良俗限制 | 借家庭、伦理或公务人员极端失实情节反复制造恶意对立 | 按目标平台、表现方式、宣扬程度核对；不是所有复仇、家庭冲突或黑暗人物都违规。P01、P04 |

## 三、发布与账号行为（C21—C26）

此组可能需要作者的发布记录、合同或平台通知。缺少记录是覆盖限制，不是已经确认的行为违规。特别参阅[番茄发布规范](https://fanqienovel.com/writer/zone/article/7237084151751376957)与[AI标识办法](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)。

| 编号 | 风险类别 | 重点核对的表达或行为 | 边界与依据 |
| --- | --- | --- | --- |
| C21 | 标题、封面、简介与营销失配 | 色情挑逗、侵权图片、严重误导、资料与书名作者不符 | 图片不可读则封面未完成审核；格式或收录问题不自动意味着账号要被封。L02、P01、J01 |
| C22 | 站外违规引流及不当盈利 | 引导购买或索取违规内容、私下交易、违规广告与链接 | 目标平台可能允许部分正常交流；不能把所有站外账号都判成非法。P02、J01 |
| C23 | 恶意水文、重复拼凑与AI量产低质 | 重复灌水、无关填充、大规模粗制滥造，提醒后仍不改 | 普通节奏问题不直接等于恶意；AI辅助校对不等于量产违规，结合发布历史。P02、P03 |
| C24 | AI声明与标识违规 | 应声明的生成合成内容未声明，恶意删除或伪造标识 | 先核实内容来源、适用服务与具体平台要求；不能只凭文风鉴定AI或规定统一正文水印。L06、Q01 |
| C25 | 重复严重违规及恶意规避 | 已有处罚后反复上传同类内容、恶意改成色情内容、传授违规经验 | 需有通知与版本记录；正常修改、申诉不构成此项，不提供规避操作方案。P02、P03、P06 |
| C26 | 授权、首发独家及合同资格 | 未获许可的重复授权、与个人合同冲突的发布行为 | 依据本人合同与授权链单独核对；不能靠正文推断，也不能把违约一律定犯罪。L05、Q01及实际合同 |

## 风险判断边界

类别不直接对应封号等级。角色年龄、真实可识别性、描述目的与细节、实际平台、发布位置、传播行为及已有通知会改变结论。同性或异性关系、无CP、修仙、悬疑、现实题材等标签均不能单独作为违规证据；它们也不能替具体表达提供自动豁免。
