# 敏感内容警告、举报与封禁案例清单

核验日期：2026-11-14。范围：中国大陆网文公开发布；平台案例选取番茄公开处罚，监管案例补充起点、晋江及其他被点名平台。这是有来源的代表案例，不是完整禁书目录，也不证明历史措施目前仍有效。原因分类沿用[风险目录](risk-catalog.md)的C01—C26，来源编号见[证据索引](sources.md)。

## 1. 警告怎样使用

用户要求敏感内容提示、发布前检查，或查询被封、被举报和官方点名案例时，使用本清单。检查稿件时，先给出当前文本和规则依据，再按需引用相关案例；书名、题材或人物身份相似不产生违规结论。只列案例也不是审核用户稿件。

一条警告说明：

`当前稿位置及必要证据 → C原因分类 → 平台规则及为什么相关 → 案例与日期（如有） → 实际／可能的B处置分类 → 证据状态与未知项 → 实质处理建议`

公开名单脱敏的账号、书名保持脱敏，不检索还原。平台只公布概括原因时，不从书名猜测色情、政治、未成年人或侵权对照。举报、官方点名、处罚和司法认定分别保存，不以一种替代另一种。

## 2. 来源、状态和封禁分类分别记录

### 2.1 三种来源标签

| 标签 | 代表什么 | 不能据此认定什么 |
| --- | --- | --- |
| 平台处置 | 平台通知或公开处罚公告 | 不等于行政处罚、司法裁判或跨平台禁令 |
| 举报线索 | 可定位举报、投诉、受理回执，或公告明确提到举报 | 举报主张不等于违规成立；受理不等于已处罚 |
| 官方点名 | 监管、执法部门公布具体作品、平台或案件 | 点名、整改不自动等于作品或作者永久封禁 |

标签可并存。另记事件状态，例如“仅有举报主张”“已受理待核查”“平台已处置”“官方通报涉嫌并查处”“已公布裁判”“复核撤销／恢复”。这些状态不是所有案件必经的顺序；官方通报涉嫌时保留“涉嫌”。

### 2.2 B01—B08：按实际影响对象分类

下表为本项目的工作分类，不是平台官方处罚等级，编号不代表严重程度或处罚阶梯。

| 编号 | 处置分类 | 必须保留的范围或限制 |
| --- | --- | --- |
| B01 | 单章／素材驳回、锁定、屏蔽 | 具体章、图、简介及版本；不是整书或账号措施 |
| B02 | 作品拒收、删除、下架 | 具体作品、渠道和通知；搜索不到不足以确认 |
| B03 | 分发或推荐限制 | 实际通知或可核实措施；不能从流量下降推断 |
| B04 | 签约、奖励或收益权益限制 | 具体合同或平台依据；不将正常结算延迟归为处罚 |
| B05 | 账号禁言、临时功能限制 | 功能、期限和恢复条件；未明期限写未知 |
| B06 | 账号封禁、永久关闭或合作终止 | 按原通知分别写明；只说封禁时不能补成永久 |
| B07 | 栏目、网站或平台停更、暂停经营、关闭 | 平台及栏目、起止日期；不投射为全部作者被封 |
| B08 | 行政处理或司法程序、责任 | 区分检查、立案、整改、处罚和裁判；不合称已定罪 |

只有举报而无处置证据时，B分类写“未确认”。概括原因无法定位C细项时写“待细分”，不为编号完整而猜测。

## 5. 只有举报、尚无结论怎样警告

本清单不收录仅靠网传截图或匿名爆料的实名指控。G01—G02是明确有举报背景的查处事件；F07—F08仅支持公告批次涉及举报渠道，不能推断逐案发现方式。

作者提供举报材料时可另建待核查记录：平台、作品／章节版本、举报时间、被主张问题、原始链接或材料、是否已有受理回执及后续通知。举报主张、平台确认事实和审核者意见分列；个人材料不默认提交到公开仓库。

> 举报待核实：材料称本段涉及C19版权问题；目前仅有举报描述，未取得对照和平台结论。B处置未确认。需核对原文、权利来源及受理结果，不能标记为“已抄袭”或“已封号”。

这是格式示例，不是真实案例。后续撤回、驳回、复核撤销或恢复上架时，关联原事件补充日期和依据，不覆盖原主张，不继续把已撤销结论显示为当前有效。

## 6. 面向稿件的警告与维护

- **已有当前稿和规则依据**：先指出原文及适用条款，再引用相关案例。明确案例已处罚与当前稿可能受何措施分别成立；未经处罚通知，不能写用户已被封。
- **只有举报材料**：显示“待核实、处置未确认”，不把举报次数当平台裁定。
- **仅查询案例**：例如解释G03的2019年栏目停更，不附加用户稿件违规或现行禁令结论。

新事件保留稳定编号、平台和对象、事件／公告日期、原因原意、C分类、B分类、期限、来源标签、状态与未知项；每条能回到原文，图片能回到原公告及对应图。事实与审核推断分开，原因缺失保持未知。

本次核实8条平台记录、6条监管记录；其中含批次、同事件不同对象和抽样，条数不等于独立处罚、作品或作者总数。未读取涉案全书、账号私有通知、举报者身份或完整裁判；不提供全量敏感词表、封禁概率或过审保证。

警告用于说明依据与处理方向，不自动改稿、隐藏内容、阻断创作、代发举报或申诉。Skill可在对话中使用；本次未接入工作台界面、自动审稿或发布链路。
