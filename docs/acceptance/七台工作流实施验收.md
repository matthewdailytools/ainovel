# 七台工作流实施验收

使用隔离数据目录和原创短篇《遗铃》。原作品无需迁移。

| 实施范围 | 已复现的操作 |
| --- | --- |
| M1–M3 | 生成立项候选，修改结局后确认。生成设定使用已确认版本。立项变化后，旧草案保留原立项编号并提示作者核对。设定预检能从发现跳到双方的编号和位置，保存版的核对随确认冻结。拆解台重拆后可回到旧卡。 |
| M4–M5 | 生成或手填四级大纲和伏笔计划。新伏笔随大纲确认建账，落盘失败和提交重试不会多建记录。写作可按卷和单元定位章节，从台账跳到对应章，回读所采用手法卡的固定修订和原文。 |
| M6–M7 | 按章、卷、全书对账。必查项目受免查条件限制，篇幅目标修订会使相关旧判定过期。可生成带原文依据的语义核对和完本建议，作者单独签署。六项全绿方可完结，ZIP 包含四件材料和哈希清单。追读报告按发布版本和口径记录。 |
| 自动接力 | 可从创意、已确认立项、设定、大纲、完整已保存正文或已通过的全书体检启动。后端回归验证旧立项和旧正文依据被拒，已通过的体检若在执行前换版则暂停，作者继续后使用新体检。提供参考会话时，可以先拆解。等待作者决定、取消或回滚时保留候选和原回执，旧任务不会写回恢复后正文。 |
| 版本回滚 | 可按稳定 ID 比较单条设定的历史并恢复为新草稿。作品快照可预览差异、原位生成新修订或恢复为新分支。旧依据和回滚前版本保留，场景时点与视角绑定仍可能需要复核。 |
| 独立 Web | 浏览器离线重开可继续编辑。未提交输入可单独暂存，遇同章更新先比较，再选择新基线。冲突比较后可断网把所选稿另存为可编辑分支，重新打开后能读回选稿和来源。真实 Chromium 注入存储升级中断后原正文仍可读，重试可升级恢复。稿件包带有可验证的来源依据，支持桌面往返。 |
| M3 正式稿件包 | 独立 Web 可断网首次确认设定，往返桌面并在清库后恢复，然后对照历史起草并确认新修订。独立 SQLite 回归还验证设定旁支、包内立项和原章稿选区。立项已更新时须核对影响后再确认。缺失来源或引文校验失败时整包拒绝写入。 |
| M2 手法卡稿件包 | 保存卡片状态、历史修订及出处。桌面可查看修订和原文，默认导出只含引用地址。作者可按版选带原句、预览并取消。独立 Web 验证原句摘要，默认再次导出仍省略原句。 |
| M4 正式稿件包 | 独立 SQLite 可恢复大纲采用版、父子版本和冻结手法卡。大纲仅凭可核验的初始计划重建计划台账，若引用已推进的伏笔且缺真实故事记录，则保存历史和待恢复的采用标记。桌面可在补齐原记录后恢复，独立 Web 断网导入会提示缺失，重导出保留采用版本和依赖。复用当前立项和设定的旧大纲可在独立 Web 预览，并经确认进入新修订。 |
| 故事记录稿件包 | 保存人物、事件、人物状态、关系和伏笔的正式头、历史及精确来源。独立 Web 可由真实存稿选区确认伏笔实际阶段，导入完整档案后恢复原大纲和真实进展。缺少原故事记录或证据时保留待恢复状态。 |
| M6／M7 历史稿件包 | 保留历史范围、十项判定、作者裁定、精确正文引文和冻结交付。真实浏览器断网导入，重新打开旧体检和完本后下载 ZIP。解压四份材料与桌面逐字节一致，清单内容一致。篡改材料的稿件包未写入。 |
| 独立 Web 本机规则 | 从正式保存稿计算章、卷及全书有效字符、空稿和待复检数。按正式大纲和实际故事记录显示伏笔窗口、到期与依据待复检。字数沿用本机 M6 Unicode 16.0 口径，逐一核对 Unicode 码位。断网浏览器验证未保存草稿不会影响结果，保存后更新核算。正式体检和交付从历史面板回看。 |

- **两卷四章验收。** 同一合成作品通过正常 API 生成并修改立项，按选定资料拆解手法卡，按修订后的立项生成设定并确认硬规则，四级大纲锁定手法卡与跨卷伏笔。改纲后旧候选无法采纳，从确认大纲接力保存第四章，前面三章保留。按章、卷和全书运行体检，验证相邻章节独立有效、红黄绿、到期及原文位置。六项逐一阻断后正式完本。同一批次读取完本回执并结束，四件交付绑定同一清单。跨卷伏笔阻止会切断证据的原位回滚，卷末快照恢复为新分支后可查手法卡和伏笔历史。原分支交付与独立备份恢复后的四份材料逐字节一致，原执行回执和费用记录可查。[两卷验收用例](../../backend/tests/test_stage_three_acceptance.py)
- **隔离恢复演练。** 按正常入口确认立项、启动接力、跨两个卷末并确认完本，逐个形成可读恢复点。修改后将 SQLite 备份恢复至隔离目录，读回各节点旧稿及 M6／M7 历史。从卷末新建分支可读到已确认大纲与章稿，固定的手法卡可按新分支编号核验并回查原编号。独立手写可在快照台创建卷末保存点。[检查点用例](../../backend/tests/test_seven_stage_run.py) · [手法卡分支恢复](../../backend/tests/test_work_snapshot.py)

本机界面使用「七台工作流」导航。「整书创作」可启动自动接力，「故事与审阅」可创建和恢复快照，「离线写作与交换」可导入、导出稿件包并打开独立 Web 工作区。
