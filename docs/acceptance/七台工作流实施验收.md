# 七台工作流实施验收

使用隔离数据目录和原创短篇《遗铃》。原作品无需迁移。

| 实施范围 | 已复现的操作 |
| --- | --- |
| M1–M3 | 生成立项候选，修改结局后确认。生成设定使用已确认版本。上游立项变化后，旧草案保留原立项编号，作者逐条核对才能重新确认。拆解台重拆选段后仍能回到旧卡。 |
| M4–M5 | 生成或手填四级大纲，作者载入候选后可修改、保存、确认。写作可按卷和单元定位章节，从台账跳到对应章，并回读章纲采用的手法卡及所选原文。手法卡改版后仍能回到已冻结的依据。 |
| M6–M7 | 按章、卷、全书对账。必查项目受免查条件限制，篇幅目标修订会使相关旧判定过期。可生成带原文依据的语义核对和完本建议，作者单独签署。六项全绿方可完结，ZIP 包含四件材料和哈希清单。追读报告按发布版本和口径记录。 |
| 自动接力 | 可从创意、已确认设定或大纲启动，沿用子任务预算和回执。提供参考会话时，可以先拆解。等待作者决定、取消或回滚时保留候选和原回执，旧任务不会写回恢复后正文。 |
| 版本回滚 | 作品快照可比较差异、原位生成新修订或恢复为新分支。旧依据和回滚前版本保留，场景时点与视角绑定仍可能需要复核。 |
| 独立 Web | 浏览器离线重开可继续编辑。支持双标签冲突保稿、缓存更新回退及稿件和历史的桌面往返。稿件包带有可验证的只读立项、设定、大纲、体检与完本依据。编辑之后仍可查看原修订对应的证据。 |

本机界面使用「七台工作流」导航。「整书创作」可启动自动接力，「故事与审阅」可创建和恢复快照，「离线写作与交换」可导入、导出稿件包并打开独立 Web 工作区。

验收使用 Chromium 和离线模型桩。已验证主流程、语义建议的待签与核对路径，以及断网重开、双标签冲突、缓存失败回退和注入配额错误时保留草稿。Chromium 原生容量耗尽、真实模型创作质量和独立桌面壳的可见窗口仍待验证。云同步见 [双端验收](七台云同步验收.md)。

复审后的合并浏览器回归 19 项全部通过，覆盖立项、设定、大纲、手法卡回源、语义候选、完本交付、追读、自动接力、回滚、离线和双端同步。先构建，再设置 `AINOVEL_SYNC_E2E=1`，运行 `npx playwright test conception-workbench outline-workspace outline-generation workflow-inspection book-completion seven-stage-run work-snapshot reading-metrics offline-workspace cloud-sync` 可重跑。

入口见 [七台设计](../../七台创作工作流设计.md)、[离线浏览器验收](../../tests/e2e/offline-workspace.offline.spec.ts)、[自动接力验收](../../tests/e2e/seven-stage-run.offline.spec.ts)。
