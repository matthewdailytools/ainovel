# 七台工作流实施验收

使用隔离数据目录和原创短篇《遗铃》。原作品无需迁移。

| 实施范围 | 已复现的操作 |
| --- | --- |
| M1–M3 | 生成立项候选，修改结局后确认。生成设定使用已确认版本。拆解台可重拆选段，已引用的旧卡保留对应修订。 |
| M4–M5 | 生成或手填四级大纲，作者载入候选后自行保存和确认。从设定台账或伏笔台账跳到写作。写作建议冻结使用的章纲，大纲换版后历史依据仍可查看。 |
| M6–M7 | 按章、卷、全书体检，保留判定与原文选区。六项全过才可完结，ZIP 包含四件材料和哈希清单。追读报告按发布版本与统计口径保存。 |
| 自动接力 | 可从创意、已确认设定或大纲启动，沿用子任务预算和回执。需要作者核对时停在体检或完本处，处理后可继续。 |
| 版本回滚 | 作品快照可比较差异、原位生成新修订或恢复为新分支。旧依据和回滚前版本保留，场景时点与视角绑定仍可能需要复核。 |
| 独立 Web | 浏览器离线重开可继续编辑。支持双标签冲突保稿、缓存更新回退及稿件和历史的桌面往返。当前交换范围为作品与分支元信息、章节和章稿历史。 |

本机界面使用「七台工作流」导航。「整书创作」可启动自动接力，「故事与审阅」可创建和恢复快照，「离线写作与交换」可导入、导出稿件包并打开独立 Web 工作区。

17 项浏览器离线验收通过，覆盖上述主路径。Chromium 原生容量耗尽未复现，通过注入容量错误验证保稿。模型任务使用离线桩，真实模型创作质量尚未验证。云同步见 [双端验收](七台云同步验收.md)。
