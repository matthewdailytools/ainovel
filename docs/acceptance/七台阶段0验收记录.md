# 七台阶段 0 验收记录

## 操作路径

在新作品的「小说构思 → 世界设定」新增「铃声规则」，内容为「铜铃只在门内响。」保存并确认后进入写作，在正文写入「铜铃在门外响了。」展开右侧的「已确认世界设定」，打开该条目，选择「用此设定对账 → 运行设定对账」。结果中的两个链接分别定位冻结的设定原文与当时的正文段落。

本阶段使用现有构思确认、章节保存和审稿任务入口。单条对账只将所选规则与本次保存稿发给配置的模型。报告保存确认标识、设定编号、章稿修订与原文 UTF-16 范围。报告状态由当前存储读取，正文或设定变更后仍可查看历史证据。单条对账不会把章节的整体验收状态改为通过。

## 验证证据

- 浏览器离线用例《遗铃》从录入规则、确认构思、编辑正文到运行对账，实际检查两个证据链接的键盘焦点。另一会话修改章稿后，确认原结果过期且仍展示原文。
- 后端离线模型桩分别覆盖正常检查、模型运行中修改正文、模型运行中修改设定。核对新内容未被覆盖、历史修订可查、缺失规则拒绝排队、UTF-16 范围精确及独立 SQLite 备份可读回同一报告。
- 桌面启动与本机 Web 继续共用原来的本地服务和存储入口。本轮通过浏览器和隔离数据库验证，未另行启动可见桌面窗口。模型只用离线桩，真实模型判断质量留待单独验证。

验证入口见 [端到端用例](../../tests/e2e/conception-workbench.offline.spec.ts)、[后端用例](../../backend/tests/test_setting_review.py)。
