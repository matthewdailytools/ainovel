- 资料官方 EPUB 导出曾返回 HTTP 503，未视为成功。转用明确标注范围的 MediaWiki 官方单页面通道；《三字經》页面实际为版本目录，不冒充正文。随后从可见版本入口取得《三字經釋句》文本。
- 对实际文本搜索「人之初」，命中 UTF-16 48—51；从命中打开来源，保存摘录与用途笔记，返回写作页可在资料包中主动选择该摘录。未命中的「之初」最初是在版本目录中查询，空结果与当时覆盖一致。
- 真实模型选区改写后，差异比较、采纳生成修订 5、恢复采纳前稿为修订 6 均已实测；旧稿、候选和采纳记录保留。生成时原稿从不可变修订读取，已采纳候选不会再次套用补丁形成虚假的差异。
- 排队时继续手写并保存，任务在付费调用前因基线改变停止，没有覆盖新正文。
- 已生成候选后继续手写为修订 7，再次采纳旧候选返回故事基线冲突；作者新句保持，随后可拒绝候选。生成文本有「八码七码」等无关尾句的负例，未因此记为表达质量通过。
