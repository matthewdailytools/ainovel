## 已实测的本机操作

- 浏览器创建独立的「界面验收 · 渡口手记」，无大纲、人物卡或前置模型操作即可写作。
- 输入中文、换行、😀及扩展汉字𠮷，保存后刷新可恢复；第二稿保存后可将第一稿恢复为新修订，原有修订保留。
- 浏览器实际触发在线备份并恢复到隔离目录，数据库完整性为 `ok`；包含作品、章节、历史、事实和书库计数。
- 资料官方 EPUB 导出曾返回 HTTP 503，未视为成功。转用明确标注范围的 MediaWiki 官方单页面通道；《三字經》页面实际为版本目录，不冒充正文。随后从可见版本入口取得《三字經釋句》文本。
- 对实际文本搜索「人之初」，命中 UTF-16 48—51；从命中打开来源，保存摘录与用途笔记，返回写作页可在资料包中主动选择该摘录。未命中的「之初」最初是在版本目录中查询，空结果与当时覆盖一致。
- 真实模型选区改写后，差异比较、采纳生成修订 5、恢复采纳前稿为修订 6 均已实测；旧稿、候选和采纳记录保留。生成时原稿从不可变修订读取，已采纳候选不会再次套用补丁形成虚假的差异。
- 排队时继续手写并保存，任务在付费调用前因基线改变停止，没有覆盖新正文。
- 320 像素窄屏写作、整书、审阅页及 768 像素书库实测可重排，页面宽度与滚动宽度一致；桌面 1280 像素核对写作及差异预览。其他键盘、对比度与新交互的最终检查继续更新。

## 运行与数据保护补充

已从 Codex 虚拟化的 LOCALAPPDATA 位置迁移到固定的 `C:/Users/matth/.ainovel`。迁移使用 SQLite 备份机制，校验 31 个工作版本的导出哈希、全部费用行和资料原件 SHA-256 一致；原目录保留并写入停用标记，拒绝将其重新作为活动账本。桌面和 Codex 启动共享同一目录。

启动命令已实际启动 API 与独立 Worker；端口占用在派生 Worker 前失败，Worker 随启动进程或停止标记退出。正式替换备份会拒绝仍在运行的 API／Worker。下载任务重启后明确标记中断，不自动重新下载。

明确重做曾误复用旧步骤的缓存，已增加独立生成批次并以回归验证；普通断点恢复继续复用已知完成步骤。历史事实重新提取后标为失效保留，不删除既有证据。所有开发中恢复与拒绝操作作为干预保留，不视为无干预生成。

中文字符串输入不等于真实输入法组合过程的实测；完整屏幕阅读器与 WCAG 符合性没有据此宣称通过。

## 剩余验收与限制

1. 两个独立整书版本的实际章数、字符数、完整结局、严重矛盾、故障恢复和导出一致性，须在批次终态逐项更新。
2. 作者的表达、情绪与人物声音判断；同难度基线与工具总投入，不能由模型自评替代。
3. 百章压力、题材专项质量、复杂事件图及 PDF／OCR 不属于本轮已验证能力。
4. 官方下载受来源与网络可用性影响；单页面获取不会自动跟随子页面，EPUB 支持无 DRM 及可解析的 UTF-8 spine 正文。
5. 上下文按文档所述范围装配，事实自动提取可被作者更正；引用可回源不等于事实提取与审稿判断必然正确。
