# 小说构思工具验收记录

日期：2026-11-14。需求：增加小说构思工具，简单易用。

## 实现与使用

主导航增加「小说构思」。选择作品后写一句想法，点「帮我展开」，得到一个可编辑的故事方案；修改后「采用构思」，再「去写作」。不要求先创建章节或准备人物卡、世界观、大纲。未配置模型仍可直接采用作者想法。历史构思与当前约定收在折叠区。

生成使用现有账户、共享预算、持久化任务和候选链路，提示词标记为「小说构思工具/1.0.0」，仍通过 `ideation.explore` 执行。默认只请求一个简短方案，包含核心故事、人物目标、阻力代价、开篇与发展建议。生成前说明发送当前想法及本版本设定、约定和相关故事上下文，不发送书库资料。

采用通过新增的 `POST /api/branches/{branch_id}/ideas/adopt` 保存。只更新作者契约的 `direction`，保留原作者文字、其他结构化字段、来源记录和历史版本，不修改正文或故事事实。服务器在同一个 SQLite 写事务中校验工作版本、候选归属与修订、请求幂等性，保存新意图、更新故事修订与回执。旧方案可以经作者重新核对后采用，不能借来源引用清空当前锁定项。

沿用现有 artifacts、receipts、branches 数据结构，无新增依赖或存储迁移。原生成模块的公开产物说明由 intent 更正为实际的 advice，并增量更新模块版本。采用接口与生成接口类型已同步至 OpenAPI 和 TypeScript。

## 业务验收与限制

已用隔离的原创数据和离线模型替身验证使用流程、候选隔离、作者采纳权、锁定保留、取消恢复和备份恢复。AI候选只供选择，不自动成为正文或已发生事实。

本轮没有调用付费模型，不把离线固定响应当成构思质量评估。方案的文学质量、题材适配和实际使用收益待作者试用反馈。

未采用的编辑以当前浏览器窗口的sessionStorage保留，离开时有保护；浏览器禁用存储或存储写入失败会提示复制或采用后再离开。清除浏览器数据或关闭窗口不保证保留未采用编辑。已生成候选与已采用方向保存到本机数据库，并可通过现有备份机制恢复。

重启本机API与Worker后使用新增采用接口；生产前端已构建。没有自动重启正在执行的创作任务或进行部署。
