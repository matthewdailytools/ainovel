# 小说编辑器设计与原型验收记录

日期：2026-11-15。范围：[21号设计](../../21-小说编辑器调研与设计.md)与[独立交互原型](../../novel-editor-prototype.html)。生产编辑器、后端、模型配置、正式稿件与存储格式没有变更。

## 成果与适用规则

- 设计：6种写作产品的官方资料、3种编辑框架与原生控件的取舍、当前实现差距、23项功能目录、优先级、布局、状态、接入顺序和14条评审脚本。
- 原型：章节编辑与新建、浏览器保存、本章查找替换、演示候选、过期保护、取消失败重试、版本比较恢复、资料勾选、便笺、排版专注、当前章下载。
- 复用仓库已有 Node.js 24 与 Playwright，无新增依赖。预览服务只绑定 `127.0.0.1`，按白名单提供原型HTML／CSS／JS及设计文档，不提供仓库通用静态访问。
- 已读取工程、任务、业务、设计、UI、编码、质量、安全、数据及架构规范。原型存储和演示候选的限制在设计与界面中标明；新增建议未写入业务规范。

### 浏览器测试覆盖

1. 中文、换行、emoji、含HTML样式文本的编辑、标题与便笺刷新恢复；输入只按文本显示。
2. 新建空章、切章、原章正文与归属保护。
3. 候选仅预览；采用后保留原稿；恢复旧稿产生新修订。
4. 作者改稿后候选失效；生成取消、失败重试、切章后旧结果不能改新目标。
5. 字面查找、单处替换、带数量确认的全部替换、其他章不变、替换前历史保留。
6. 保存失败保留最新稿并阻止切章；下载内容与当前稿、单列便笺一致；恢复保存后提示清除。
7. 另一窗口实际保存后本窗口停写；损坏存储不被演示数据覆盖。
8. UTF-16选区中的emoji保留，续写在选区末尾插入；恢复相同内容也产生新修订。
9. 浏览器存储拒绝写入时不显示已保存，最新内容仍能编辑。
10. 资料开关、键盘快捷键、组合输入事件保护、弹窗焦点进入与返回、专注、字号与夜读；截图与对比度测量。
