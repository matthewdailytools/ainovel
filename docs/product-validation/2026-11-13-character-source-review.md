# 自动维护人物自由文本的来源复核

日期：2026-11-13。范围：自动整书／阶段批次在正文采用后的结构维护。此记录说明工程保护、确定性验证和剩余质量边界；不追认既有小说通过。

## 问题与本次行为

此前，结构候选中的人物 `notes`／`profile` 虽然能够定位原文，但自由文本中的断言是否得到原文支持，没有独立复核。严格引用位置与语义真实是不同要求；来源逐字匹配并不能证明档案中的推断成立。

现在，自动维护先保存稳定结构候选，再对新人物非空说明、档案，以及既有人物本次实际变化的非空说明、档案，合并执行一次独立来源复核。没有这些自由文本的身份候选、未发生变化的旧字段，不新增该调用。复核通过仍须满足原有自动采用政策；人物档案改写、旧事实纠错等既有人工核对边界不放宽。

独立契约版本为 `character-field-entailment/1`。模型只收到待核对字段、本项人物名称与别名、本项冻结原文，以及本任务冻结的 `brief`／`fixed`；不把已存在的人物自由文本、当前故事图、频道预设或创作契约补作来源。公共系统指令仍生效。通过既有单一 Worker、持久步骤、累计预算和取消机制执行，没有新 Worker、模型服务或队列。

每个字段返回一种结论和理由：

| 结论 | 后续行为 |
| --- | --- |
| `supported` | 完整断言得到本项来源支持时，才可继续原自动采用检查。 |
| `unknown` | 缺少充分依据，保存有效报告和完整候选，进入 `needs_review`。 |
| `contradicted` | 与本项来源冲突，保存有效报告和完整候选，进入 `needs_review`。 |

未知、矛盾是有效结论，不触发要求模型反复改判的修复；不会为通过审查删除字段、局部采用人物记录，或自动修改原稿。格式、字段覆盖或引用不合法时，复用现有有界结构／引用修复；重复的相同已完成步骤复用缓存。结果未知的网络错误停止，不自动重发。

## 持久化、并发与兼容

- 报告保存在原结构产物的 `payload.character_semantic_review`，旧报告被替换时保留在 `character_semantic_review_history`。完整模型响应仍由既有 `task_steps` 保存；报告关联调用指纹、调用标识、用量、模型、契约版本及保存 attempt。不新增数据库表或迁移。
- 输入绑定包含稳定产物标识、候选修订、故事修订，以及候选记录、原文位置和全文快照、任务约束的 SHA-256。正文、字段或约束即使在异常情况下未递增版本，内容哈希变化也会使旧结果失效。
- 每项必须完整且唯一覆盖 `record_id + field`。肯定、矛盾结论必须引用该人物本项的有效来源编号；不能借其他候选的人物来源。原句、章号、修订和 UTF-16 位置由程序复原，校验连续原文和代理对边界。
- 调用前、报告保存事务及最终采用事务分别检查当前候选、来源、任务 attempt 与租约。自动维护实际需要复核字段时，内部采用调用漏传凭证也会被拒绝；已有报告不构成省略凭证的理由。
- 已完成调用与已保存有效报告均可在新 attempt 恢复时复用。旧版或失配报告不会被补标通过，必须执行当前契约的实际复核。
- 等待／暂停检查点在短写事务内重新读取当前待维护目标和最新结果。作者恰在报告保存后采用时，保留作者已经推进的历史与故事修订，不把旧 `pending_structure` 写回。
- HTTP 人工采用语义保持不变：作者可以核对后明确选择采用，报告不替作者作最终决定。已采用的旧错误记录、真实正文和旧历史均不回写。

这是一项增加后续审查调用的保护。调用次数和用量进入已有任务及账户账本，OpenAI 两把 Key 合计 USD20、DeepSeek CNY80 的历史累计限制不重置。本轮确定性验证没有生产模型费用。

## 工作台入口

在「故事与审阅」的「按保存稿整理人物、事件、状态和伏笔候选」中选择结构产物，可查看人物字段来源复核状态，并展开逐字段结论、理由、原文、修订与位置。缺失、格式异常、候选修订不符及来源失效分别提示，不能显示为当前来源支持。

新增「刷新候选与复核报告」入口，保留当前选择和输入。切换作品、候选或重复刷新后，迟到响应不会覆盖新的目标。人工采用仍走既有版本校验；展示的模型结论不等于作者认可。

## 判定与剩余限制

本次验证证明候选、报告、来源和采用事务之间的工程绑定及恢复行为；不证明模型的语义判断一定正确。一个字段内含多个断言时，模型仍可能错误判断“全部得到支持”；自动维护仍需要真实反例评测与后续原文审阅。

本次不追溯洗白已经采用的错误档案，不自动修改旧结构或真实稿件，不给人物档案新增事实性质字段，也不把本例词汇硬编码成全局禁令。关系两端相同的既有自动保护保留原样，人工明确采用仍可用。

已有一项作者盲评偏好记录，不代表本功能或整部长篇已得到文学质量认可。其余样例、整体文学质量、连续十章、两套36章及作者总投入收益仍按各自证据单独判定，未通过的范围保持未通过。
