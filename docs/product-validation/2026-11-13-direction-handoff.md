# U01：作者选择方向后进入本章补写

日期：2026-11-13。范围：13号设计 U01 / U02 的“手写卡点→方向建议→作者选择→补写”连接。

## 本次实现

- 方向建议保留自由文本，不解析编号或自动选中。作者填写、修改“作者选定的本章方向”，再明确点击“将选定方向载入本章补写（不生成）”。
- 只切换现有写作表单到 `writing.expand_plot` 并载入作者选定文本；固定条件、写法和已选资料包保留。不产生模型任务，不采纳建议或正文，不写入设定与故事事实。
- 当前“情节或具体要求”非空且将被替换时明确确认，取消后保留两处输入。未载入方向和已载方向均进入离开保护，切换章节、作品和页面先允许作者保留当前工作。
- 载入前重新读取来源建议，核对作品、工作版本、目标章、候选版本与拒绝状态；读取期间切换目标或编辑表单时停止套用。无目标章建议不能静默套用到当前章。
- 旧正文修订建议显示原修订和当前修订，提醒作者核对。来源标记保留建议 ID、候选版本、作品／版本／章、原修订和载入时修订。提交补写时复核来源，并把来源标记写入既有任务指令；正文仍沿用现有保存、CAS、取消、候选拒绝／采纳与历史恢复。
- “恢复最近任务的输入”恢复可编辑作者文本及结构化来源；错误章节和异常来源记录停止恢复，保留当前输入，不能降成无来源要求绕过检查。
- 作者可清除来源标记并保留已填写要求，或继续手写；没有新增主导航、后端 Schema 或依赖。

## 首次失败与修正

1. 精确 `getByLabel` 在已有预填 textarea / select 中会把子文本计入 label 匹配，测试超时发生在表单设置阶段，API 尚无模型任务。改按 textbox / combobox 的可访问名称定位，保留业务断言。
2. 初版测试连续注册 `once(dialog)`，未等待保存后异步弹窗，下一次处理器可能附着到前一弹窗并重复处理。改成各次 `waitForEvent('dialog')` 与操作一同等待，并等待按钮重新可用，保留取消及确认两条路径。
3. 修正后方向用例通过；本次失败轨迹保留于仓库外 `C:/Users/matth/.ainovel/acceptance/u01-direction-2026-11-13/` 的 `label-selector-failure` 和 `dialog-timing-failure` 子目录。未通过删除断言、提高超时或跳过用例制造通过。
