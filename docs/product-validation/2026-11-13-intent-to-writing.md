# U02：一句想法到本章正文的独立验证

日期：2026-11-13。对象：当前工作台的一句想法、创作约定提案、可选设定设计、正文补写和版本恢复。只用隔离 API／持久 Worker 路径及明确的确定性模型替身，不调用真实模型，不操作日常实例、真实稿件或用户标签页。

## 发现与修复

首轮真实 UI 验证发现：世界、人物及粗纲在写作页生成时一律携带当前章节 ID，“采用此结果”保存为已采用的章级产物；后续上下文只装配无章节归属的本书设定，因此这些产物没有参与后续创作。初轮测试在“后续上下文应含三类设定”处失败，不能以手动转存代替产品连接完成。

本次增加明确范围选择，复用既有接口，无后端字段或迁移：

- 世界、人物、粗纲默认选择“本书设定（采用后供后续任务使用）”，生成请求的 `chapter_id` 和 `base_revision` 为 `null`；作者确认后进入当前工作版本的后续任务上下文。
- 作者可改选“本章资料（仅保存参考）”，保留目标章及正文基线；采用只保存为本章参考，不进入全书设定。没有章节时明确阻止该范围，仍可生成和采用本书设定。
- 候选展示范围和用途，按钮分别为“采用为本书设定”与“保存为本章参考”。设定只是创作安排，不自动成为已发生的故事事实。
- 恢复最近设计任务时，根据其原 `chapter_id` 恢复本书／本章范围。旧章级产物不自动升级；需要改为全书用途时仍须作者在既有“其他已采用设定”表单中明确确认。
