## 判据修正

此前四个只读无头用例比较全局预算的前后快照。在其他作品正常运行模型任务时，墙钟时间内全局费用允许变化，不能据此认定本用例派发了付费操作。

本轮仅修改测试设施：[只读隔离 fixture](../../tests/e2e/read-only-live.ts) 及四个 `.live.spec.ts`。每项通过 API 新建带“后台验证 · 只读工作台”标记的独立作品、章节和固定工程样本，建立保存稿基线；这些准备写入均只针对新建样本。浏览器启动前预置当前作品/工作版本，避免先打开用户原有作品。

浏览器上下文记录全部 `/api` 写请求，只有本项测试作品的 `reading-state PUT` 且 `chapter_id` 对应本项章节可以放行。生成、改稿及任何其他目标的写请求在发往服务前阻断，并作为失败记录，不能因阻断而忽略。结束时断言其他写请求为 `[]`、测试正文与修订精确不变、测试版本模型任务数为 0；不再断言全局费用在本次测试期间恒定。

这是“**未派发生成或改稿请求，位置维护仅限测试作品**”，不是“本次完全没有写请求”。原有 UI 只读断言全部保留。
