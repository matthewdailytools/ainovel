# 长篇人物时点与多线工作台：实现及验证

本记录是长篇核心能力的阶段交付，不表示完整计划或全项目稳定性通过。

## 已实现

- 稳定人物身份、别名与档案；不同人物别名冲突会停止写入，不自动合并身份。
- 事件分别记录故事序、时间说明、线别、参与人物、前后依赖、计划／实际／未知／冲突及原文位置。同一事件可有多处呈现，不重复累计资源。
- 状态区分认知、能力、资源、伤势，以及作者／人物／读者视角；关联变化事件、失效事件及原文。按故事时点查询，未知顺序不推断；同一时点冲突并列保留，明确更晚事件的状态覆盖旧状态。
- 伏笔与承诺分别维护计划、埋设、强化、回收、保留、放弃阶段；已发生阶段要求原文，保留／放弃要求理由。模型生产完成判定读取已维护清单。
- 关系记录支持方向、形成事件、性质及来源。工作台保留四个主导航，嵌入“故事与审阅”，提供泳道、依赖图、关系图、表格及键盘操作、原文快照、卷筛选与跨卷编辑。
- 所有写入携带故事及记录基线，修订历史保留。依赖绑定父记录修订；正文、父记录或归档改变时，依赖失效沿关系传播，旧记录保留。
- 写作上下文增加有效长篇记录。未明确故事时点的状态置于待判断范围，不伪装成当前已知；提示词版本0.5.0。旧设定和事实不自动转换为精确身份或状态。

## 缺陷及复测

1. 同值选择当前作品会清空版本并停在空白：增加同值保护，无头操作复测通过。
2. 首个测试二次点击已展开的来源折叠区，隐藏了原文：改为按实际可见状态打开；未删减来源选区断言。
3. 多次呈现的事件如同时存在后文出处，原查询排除整个事件：改为保留当前叙述位置前已可见的出处，过滤后文原句；增加专项验证通过。
4. 首次专项测试误将更新响应预期为201，实际200；按接口区分新建与更新，错误码也按现有顶层契约验证。
