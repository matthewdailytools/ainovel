# 长篇拆章导入：实现与验证

本次完成正文导入闭环，不代表反向整理和全部长篇能力已通过。

## 功能

- 写作页“导入与导出→长篇拆章预览与导入”打开工作区。支持20MB内TXT／Markdown和UTF-8、UTF-16、GB18030明确编码；原文件字节、哈希和规范化换行后的文本保存于作品数据库。
- 按明确标题行建议章界，卷首文字保留为显式段。可阅读每段，修改标题和边界、按光标拆分、合并下一段；标题行保留在正文，不静默删内容。
- 每段明确追加、替换指定章或跳过。同名不自动替换；重复正文必须显式允许。修改章界后提示原建议匹配范围已变化，以确认时检查为准。
- 章界和映射草稿可保存及刷新恢复；多窗口草稿修订冲突会停止写入。
- 全部映射先校验，正文与回执同一事务提交；替换保留原稿修订。重试相同确认返回同一回执，不重复追加。确认失败保留预览与当前表单。
- 导入后更新目录，保持当前编辑器输入，由作者选择继续的章节；不自动调用模型或采纳故事事实。
