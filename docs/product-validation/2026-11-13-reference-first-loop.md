# 参考仿写首版实现与稳定性记录

范围：书库选段、拆解卡、作者选择规则、本书方案、独立试写、对照、采纳及历史。此记录不代表全项目稳定性或文学质量通过。

## 实现

- 书库原文选区和已存摘录可建立固定来源会话，保存来源哈希、UTF-16位置、原文快照及学习目标。独立分析不要求先有小说。
- 拆解卡分别保存观察、作用解释、写法、适用边界、原文依据；作者编辑选择后显式保存。方案与试写只发送选定写法及本书上下文，不将参考原文当故事事实。
- 试写、对照使用持久任务及既有预算、候选和正文版本机制。模型检查辅助作者判断；重合报告仅覆盖本次选段，不作全书原创保证。
- 修改会话使旧规则和产物进入历史；修改候选使旧检查失效。刷新后可恢复已存会话、阶段任务和候选，查看旧规则与方案产物。
- 正文采纳保留原稿修订，结构化分析与方案禁止通用直接采纳到正文。

## 发现及处理

1. 浏览器测试最初错误地用input value断言CodeMirror可编辑区域。改为正文内容断言，复测通过；不是正文丢失。
2. 会话重开后无法看到活动阶段。增加按会话查询持久任务，展示历史任务及旧规则产物，补充刷新重开测试通过。
3. 新增任务状态断言误写“已完成”，实际文案为“候选已生成”。修正测试文案，复测通过。
4. 备份恢复测试尝试在活动测试API上正式恢复，被既有服务保护正确拒绝。改为实际解包到隔离目录、重开数据库核对，未绕过服务保护。
