# 首轮结构输出上限配置

日期：2026-11-14。状态：前端、后端与 CLI 专项验证已完成；本轮全量、构建、无头浏览器、提交、推送与本机更新结果待根任务补充。

## 触发与范围

既有真实场景提取曾在首轮8192输出上限处截断，之后进入已知截断的有限修正；这些原任务及费用记录保留，不能通过修改历史配置将其改记为成功。本次允许作者在**创建新任务时**明确选择首轮结构整理的输出上限，减少只能依赖后续修正的限制。配置更大不保证输出完整、来源真实、时点核实或文学质量通过。

仅调整独立结构提取与工作流结构维护的首轮输出设置。不改变规划、正文生成、普通审稿、人物字段来源复核及其余调用的输出配置，不改变提示、来源范围、有限修正次数、模型能力、预算、采纳或原稿保护政策。

## 前端入口与冻结行为

- **独立整理**：在「故事与审阅 → 按保存稿整理人物、事件、状态和伏笔候选」内展开「结构整理的输出设置」，选择「首轮结构输出上限（tokens）」的8192或16384，默认8192。所选值进入 `StartExtraction.max_output_tokens`，与章节范围、来源故事修订、场景选项和账户一起参与请求幂等签名。
- **整书／阶段工作流**：开启「每章采用后整理人物、时点、事件和伏笔」时，显示同一低频设置。所选值进入 `WorkflowInput.structure_max_output_tokens`，并纳入既有表单签名、离开保护与请求签名。关闭结构维护时不展示该设置、不增加无关前置门槛，请求沿用默认8192。
- **草稿保护**：独立整理的未提交范围、场景选项和上限加入离开保护；成功提交后标记为已提交。后续选择采用哪些结构候选，不会被误算为这份设置草稿。工作流沿用现有未提交表单保护。
- **已创建任务**：工作流显示「本批次结构输出政策」，读取该任务冻结的 payload，不读取当前新建表单。旧任务缺少该字段时明确显示沿用8192；合法的 CLI 自定义整数按实际值显示。异常冻结值显示待核对，不静默改成默认值。
- **恢复与换账户**：仍由既有恢复／续跑接口沿用服务端冻结值，新表单的选择不覆盖旧任务。调整旧任务的上限须创建独立新任务，不能通过续跑升级历史设置。

界面明确说明：该选项只控制**首轮**。既有已知输出截断的有限修正最高仍可使用16384；不能把首轮8192描述为每次调用绝不会超过8192。选择16384可能增加费用预留，仍受同一任务和共享预算限制。

## 后端契约与执行边界

| 入口 | 字段 | 默认与校验 | 生效范围 |
| --- | --- | --- | --- |
| 独立保存稿整理 | `StartExtraction.max_output_tokens` | 默认8192；严格整数64—16384 | 当前新结构整理任务的首轮调用 |
| 半自动／全自动工作流 | `WorkflowInput.structure_max_output_tokens` | 默认8192；严格整数64—16384 | 本工作流各章结构维护的首轮调用 |

字符串、布尔值、小数、空值及越界值在 API 边界拒绝，不先创建任务。前端只提供8192／16384两个常用选择；API与CLI保留合法整数范围。

独立整理将所选上限传入既有模块请求。工作流每次结构维护从冻结 payload 读取；旧字段缺失时使用8192。实际请求及费用预留采用该值，但实际模型上下文窗口、请求体字节上限、任务和共享费用边界继续检查；选择16384不绕过发送前拒绝机制。

默认8192与旧省略字段的同 nonce 重放兼容，返回原任务，不给旧 payload 补字段。显式16384不能冒充同一旧请求。续跑省略字段时保留原冻结值；显式冲突被拒绝，旧缺字段继续保持缺字段。普通写作模块的 `max_output_tokens` 不因这个结构专用兼容规则被改为等价请求。

## CLI 与历史运行目录兼容

`quality_longform` 新增 `--structure-max-output-tokens`，接收64—16384的整数。新运行省略时使用8192；新选择记录在独立 `workflow_options`，不改变 `RunSpec`、既有配置签名或原创简报 SHA。

恢复既有运行目录时：

- 省略参数继承该运行冻结的值；若旧目录没有字段，按8192解释，但不回填旧字段或重写已冻结 payload、哈希与 nonce。
- 显式参数与冻结值不同，在复用或派发前拒绝，要求使用新运行目录。
- 旧 `workflow_options` 缺失，或仅含人物字段修订／情节核对选项的历史记录，仍兼容；不会因此开启新能力或升级输出上限。

CLI帮助同时说明首轮与有限修正的区别，以及原预算保护保持不变。该参数不恢复失败任务、不重发未知结果，也不自动采纳任何候选。
