# 作者来源范围、分歧保留与参考首次复检

日期：2026-11-16。接续[接收范围与正文流向关联](2026-11-16-source-scope-and-flow-instance-checks.md)。本记录区分源码验证、日常运行及真实模型质量，不以工程检查替代作者评价。

## 本轮行为

开启情节核对的新普通补写、保存稿检查、半自动作者情节及参考试写／对照，接入独立作者来源观察。观察只读取本次作者原话及连续来源单元，在生成正文前完成；不读取候选、参考原文、频道题材、全书约定或未来章来证明原话已经明确。上述资料在原有创作及独立检查环节继续各按用途使用，不成为来源解释的证据。

观察与解释分开保存。普通命名目的地、另抄许可、排除某人或一份材料不能自动变为排除全部其他接收者。第二次解释可保留与先行观察的真实分歧，并记录未知及原因；先行模型分类不作为作者真值。只有真实语义未明才停止，角色称谓清楚但没有再次写姓名，不自动算作歧义。

执行前冻结`authored-source-scope/1`的原话、目标、来源与输入摘要，任务创建事件及分阶段回执相互核对。普通补写／半自动／试写的来源未知在正文前停止；只读检查保留未验证状态。未知调用不重发、不换账户绕过，不重置历史费用。旧任务、nonce及已付缓存沿用原版本。

新全自动准备采用独立`workflow-plan-recipient-scope/2`。原Scope1保留逐字请求兼容；Scope2允许有效unknown，在开放选择、保持核对及正文前停止。工作台同时识别两个已知版本；完整解释已经返回且存在语义分歧时，不提供“三次结构无效后重做”的入口。

参考候选已有正式来源解释时，新的对照检查继承原始情节解释和来源回执，不因正文编辑重新定义要求。本次显式正文检查仍采用当前FLOW执行版本。候选的原方案与当前情节／固定条件不同，先创建新方案／试写，不能借旧稿反推新要求。

修复区分“没有解释”和“已有旧版解释”。没有解释时，先核对候选生产任务冻结的方案与当前原话／固定条件相同，再首次建立独立来源检查，保留本次新版正文核对。候选编辑内容不进入来源观察。已有旧版解释继续按其版本读取。新增正式API回归覆盖首次复检及编辑候选后的首次复检，原生产任务和旧来源保持。
