# AI章纲材料称谓关联与独立范围核对

日期：2026-11-16。接续[真实来源核对停点](2026-11-16-automatic5-source-object-alias-stop.md)。本轮补齐同一材料用不同称谓时的显式关联；工程验证与真实模型质量分开判定。

## 问题与实际行为

旧范围纠偏以给出方、接收方、物品字符串和阶段严格匹配。物品只是用了不同称谓，也可能无法关联；反过来，直接按相似词合并又会把原件、不同副本或不同次传递混在一起。

工作台增加默认关闭的“核对材料的不同称谓”。作者先读取对应政策的预览、主动选择原P事项，再确认费用并提交。切换选项后必须重读依据；生成摘要期间换选项、切目标、编辑正文或来源变化，均不能沿用旧预览提交。原物品字符串、原文观察、历史备注和正文保留。

执行顺序为：

1. 原文盲观察保持旧帧，只读冻结有效AI章纲，不读取旧P、候选正文、旧正文结论或自由操作原因。
2. 只有精确关联不足时增加独立称谓核对。给出方、接收方和阶段仍须相同，全部可比观察逐一核对；只有唯一同次、同一实物／信息实例有据且其余备选有据排除，才形成关联提案。不同实体副本也不自动表示不同信息，无法区分时保持未知。
3. 末次独立核对仍回到全部原事项、历史备注、固定条件与来源，再核称谓关联。真正排他、否定、条件、阶段及未选事项保持；不足以仅改范围两字段时继续待核对。

唯一精确匹配无需追加关联调用，基础两步仍执行。需要关联时可能增加一步，失败及修正也计费；界面已明确区分基础步骤和可选额外调用。

来源回执仅供只读审阅。就绪后仍须另外读取正文复检依据并显式提交；不自动生成、采纳、恢复批次或推进下一章。初段关联有据而末次保持未知／不符时，正文入口继续禁用。

## 兼容与保护

开启选项使用`prepared-source-scope-correction/2`及`scope-corrected-candidate-recheck/2`。未开启时从请求中移除新增false字段，旧`/1`输入、冻结来源、创建见证、nonce和已付模型帧保持原形；旧任务不会自动升级。

新来源任务、称谓关联及正文复检分别核对创建见证、来源和候选版本。正文POST不携带来源开关，而由所选就绪回执决定政策。FLOW2、条件性全书约定及有限修订政策保持；编辑后的旧检查继续作为历史依据展示。

未知提交保留稳定标识，只查原请求；404、空回执或网络错误不授权重发。未知调用、费用不足、旧尝试晚返回及生成时改稿均有保护。关联、范围回执和正文报告不能从普通候选编辑或采纳入口改为正式事实。
