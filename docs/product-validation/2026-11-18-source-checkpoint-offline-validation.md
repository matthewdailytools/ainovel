## 用原检查点验证

以 SQLite 只读连接对稿件库和独立账本建立一致性副本，复制前后逐表核对逻辑摘要，副本与原数据一致。测试从原任务标识进入现有恢复接口，使用真实 Worker 和进程内模拟传输。每个场景有独立副本，避免用上一个场景的测试状态替代原停点。

| 两种原检查点各执行一次 | 离线观察结果 |
| --- | --- |
| 新观察返回结构有效的合成结果 | 进入各自原有情节解释步骤。在解释派发前记录入口，目标章仍空。 |
| 新观察返回合法未知 | 单次模拟调用后停在来源核对，未派发解释或正文。 |
| 模拟超时，缺少完整回执 | 查到账本上的未结记录，并确认完整步骤缺失。再次恢复后调用计数仍为一。 |
| 三份不同的无效结构返回 | 封存三份回执并停止。重复提交显式重核被拒绝。 |

八个场景均核对已保存稿件、章节修订、两任务的原始规划、旧来源阶段和旧事件。原费用行及其元数据逐项保留，新增模拟费用仅写到各自隔离账本。外部模型调用为零。所有语义结果均来自合成回执，真实来源核对和两套12章整书仍待验证。

私有证据位于 `book-exit-execution-frozen-20261117/two-source-stops-offline-20261118/`，包含副本校验、隔离操作记录与已脱敏摘要。真实原话、稿件和账本留在仓库外。
