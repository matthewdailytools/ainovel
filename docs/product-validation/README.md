# ainovel 全项目验证记录

日期：2026-11-13。范围覆盖整个 ainovel，参考仿写是其中一条链路。

## 执行顺序

参考仿写首版 → 长篇核心能力及可视化 → 全项目稳定性与修复复测 → 真实模型质量评估 → 作者盲审。

- 当前日常实例是主要验证对象；浏览器使用独立后台会话，测试作品明确标识。
- 破坏性故障、迁移失败和覆盖恢复在一致性备份的隔离副本执行。
- 现有小说、18／15章及四份A/B候选不自动改动或采用，费用账本不重置。
- 两个OpenAI账户共用USD20，DeepSeek共用CNY80；优先DeepSeek，所有失败计入累计预算。
- 稳定性与质量分别判定。存在数据误覆盖、错误采纳、跨作品污染、预算失效或不可恢复损坏时，不进入质量阶段。
- 本目录不存真实稿件、完整提示词、凭据或模型原始输出；证据保存在仓库外，摘要须脱敏。

## 文件

- [需求场景矩阵](需求与场景矩阵.md)：痛点、需求、作者状态、场景和功能覆盖。
- `matrix.json`：模块目录；所有新一轮验证初始为not_run，不继承历史测试结果。
- `runs.json`：追加式运行摘要，每个记录包含ID、日期、提交版本、模块、场景、阶段、结果、Markdown记录及修复关联。
- [HTML历史](index.html)：由结构化记录生成，支持筛选，不执行Markdown中的脚本。

生成历史：`.venv/Scripts/python.exe scripts/build-validation-history.py`。
